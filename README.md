# Tyuiu.KonevIA.Sprint7 — Заказы
Вариант 10. Конев Илья Андреевич, НТм-25-1.

Откройте Tyuiu.KonevIA.Sprint7.sln в Visual Studio 2022 и назначьте Project.V10 запускаемым проектом. Требуется рабочая нагрузка «Разработка классических приложений .NET» и .NET 8.

## Работа
- Файл → Открыть пример загружает вымышленные заказы. Сохраните свою копию через «Сохранить».
- Добавление и редактирование: карточка заказа. Номер уникален, обязательны номер, фамилия, имя и товар. Стоимость рассчитывается из цены и количества.
- Поиск работает без учёта регистра. Статус, даты исполнения включительно и сортировка применяются совместно.
- Сводные показатели и диаграмма относятся к текущей выборке. Отменённые заказы учитываются; исключите их фильтром статуса при необходимости.
- Сохранить сохраняет всю базу. Экспорт сохраняет текущую выборку. После экспорта несохранённые изменения основной базы остаются.
- Удаление подтверждается. При закрытии, открытии другой базы или создании новой предлагается сохранить изменения.

## Формат CSV
UTF-8, разделитель `;`, первая строка — заголовок из Data/Orders.csv. Дата `yyyy-MM-dd`, цена без разделителей тысяч (точка или запятая), количество — положительное целое. Кавычки и переводы строк внутри полей поддерживаются. Один заказ содержит одну товарную позицию.

## Структура
- Project.V10 — Windows Forms: меню, панель инструментов, подсказки, карточка, таблица, фильтры, статистика, диаграмма, справка.
- Project.V10.Lib — модель, валидация, запросы, статистика, чтение/запись CSV.
- Project.V10.Test — MSTest: CSV, фильтры, сортировка, статистика, валидация.

Видеокурс по частной ссылке недоступен инструменту просмотра; реализация основана на письменном ТЗ и присланных образцах Sprint6.

## Ограничения и защита данных
Цена до 1 трлн ₽, количество до 1 000 000, текстовые поля до 500 символов. При ошибке порядка дат выборка пуста. Экспорт в файл открытой базы запрещён: используйте отдельное имя. Новая/открытая база сбрасывает старые фильтры. Статистика количества использует 64-битное целое.
